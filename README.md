# MVisualizer

This is Tyler's particle audio visualizer, made in Processing. It draws 800 red particles in a ring that react to the music. The background flashes on the loud parts, and the logo pulses on the kick.

## How to run

1. Install Processing.
2. Install the Sound library: Sketch > Import Library > Manage Libraries.
3. Open `MVisualizer/MVisualizer.pde`.

The sketch needs the song file `Between the Storms 146bpm Bm.mp3` in `MVisualizer/data/`. The logo `ARKAID_LOGO_WHITE.png` is optional; put it in the same folder if you have it. Those files are not included in this repo.
